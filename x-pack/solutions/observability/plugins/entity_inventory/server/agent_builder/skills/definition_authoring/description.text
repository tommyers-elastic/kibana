Create, review or change entity inventory definitions, the documents that tell Kibana how to list, count and detail one kind of entity (pods, hosts, services, deployments, ...) live from telemetry data streams: metrics, logs, APM metrics or events. Use when asked to define a new entity type, add a data source or metric to an existing type, extend a built-in type (host, service, user) with an inventory, or debug why an inventory list is missing entities or columns.
